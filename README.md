# Заметки

Приватные заметки для двоих (Ангелина и Кирилл). PWA, работает на телефоне как приложение,
синхронизируется между устройствами. Есть режим авторства - видно, кто какой кусок текста
написал и что менял (посимвольно), но при обычном просмотре это скрыто (кнопка-глаз).

Стек: **Netlify** (статика `public/`) + **Netlify Functions** (API) + **Netlify Blobs**
(встроенное хранилище, отдельной базы не нужно). Без фреймворков.

---

## Что внутри

| | |
|---|---|
| Логин | Два пользователя, без регистрации. Пароли проверяются на сервере, сессия в подписанной куке (HttpOnly). |
| Заметки | Общее пространство: оба видят и правят одни и те же заметки. Автосохранение. |
| Авторство | Кнопка-глаз показывает подсветку "кто что написал" + подробную историю (что именно добавлено/убрано). По умолчанию скрыто. |
| Мобильность | Адаптив, устанавливается на телефон (Добавить на экран "Домой"), офлайн-оболочка. |
| Игры | Кнопка-джойстик в шапке. Четыре игры на двоих, все пошаговые: ходишь когда удобно. |

## Игры

Всё спрятано за кнопкой в шапке, в списке заметок места не занимает. На кнопке загорается
точка, если где-то ждёт твой ход.

| Игра | Что это |
|---|---|
| Морской бой | Два режима на выбор. В режиме со способностями есть радар (сканирует 3 на 3), залп (3 выстрела ценой следующего хода) и мина. Корабли расставляешь сам: выбрал размер, повернул, ткнул в клетку. |
| Шашки | Русские: бой обязателен, бьют и назад, дамки ходят на любое расстояние, серии взятий. |
| Шахматы | Полные правила: рокировка, взятие на проходе, превращение, мат, пат и ничья по 50 ходам. |
| Виселица | Один загадывает слово или фразу с подсказкой, второй открывает буквы. Шесть промахов. |
| Кодовые имена | Кооператив, три сложности. У каждого своя карта, даёшь слово-подсказку и число, партнёр угадывает. |
| Wordle | Загадываешь партнёру слово 4-8 букв, он отгадывает за 6 попыток. Словарь не нужен. |

Правила каждой игры есть внутри - кнопка "как играть". Есть экран статистики: общий счёт,
победы по каждой игре и результаты кооператива.

Логика игр лежит в `lib/games/` (по файлу на игру + `index.mjs` как реестр). Важно: наружу
отдаётся только `view()` для конкретного игрока, поэтому чужие корабли, чужая карта и загаданное
слово не утекают сопернику даже в ответе сервера.

Поменять имена/пароли - файл [`lib/auth.mjs`](lib/auth.mjs), объект `USERS`.

## Локальный запуск

Нужен Netlify CLI (ставится один раз):

```bash
npm install -g netlify-cli
```

Дальше в папке проекта:

```bash
npm install
netlify dev
```

Откроется на `http://localhost:8888`. Локальный секрет и хранилище Blobs `netlify dev`
поднимает сам (секрет берётся из `.env`).

## Деплой на Netlify

**Способ 1 - через CLI:**

```bash
netlify login
netlify init
netlify deploy --prod
```

**Способ 2 - через сайт netlify.com:** подключаешь Git-репозиторий (или перетаскиваешь папку),
Netlify сам ставит зависимости и публикует. Publish-каталог `public`, функции `netlify/functions`
(уже прописаны в `netlify.toml`).

После первого деплоя ОБЯЗАТЕЛЬНО задай переменные окружения:
Site configuration -> Environment variables -> добавить `SESSION_SECRET`, `PASSWORD_ANGELINA`,
`PASSWORD_KIRILL`. Затем передеплой. Без них вход работать не будет.

Netlify Blobs включается автоматически, ничего настраивать не нужно.

### Про Россию

Домены `*.netlify.app` в РФ обычно открываются (в отличие от `*.workers.dev` у Cloudflare).
Если конкретный поддомен где-то режут - привяжи свой домен: Domain management -> Add a domain.

## Пароли и секреты

**Паролей в коде нет.** Они читаются из переменных окружения, чтобы никогда не попасть в git:

| Переменная | Что это |
|---|---|
| `SESSION_SECRET` | Длинная случайная строка для подписи сессий |
| `PASSWORD_ANGELINA` | Пароль Ангелины |
| `PASSWORD_KIRILL` | Пароль Кирилла |
| `VAPID_PUBLIC_KEY` | Ключ для пуш-уведомлений |
| `VAPID_PRIVATE_KEY` | Ключ для пуш-уведомлений |

Важно: значение пароля не должно встречаться в коде проекта, иначе сканер секретов Netlify
остановит сборку. Например пароль `notes` не подойдёт - это слово есть в путях и названиях.

Новые ключи для уведомлений генерируются так:

```bash
node -e "console.log(require('web-push').generateVAPIDKeys())"
```

- **Локально:** файл `.env` в корне проекта (он в `.gitignore`, в git не уходит).
- **В проде:** Netlify -> Site configuration -> Environment variables.

Если переменная не задана, вход вернёт понятную ошибку "Сервер не настроен", а не молчаливый отказ.

Имена пользователей меняются в [`lib/auth.mjs`](lib/auth.mjs), пароли - только через переменные.

## Как устроено хранилище

Данные лежат в Netlify Blobs: каждая заметка - отдельный блоб (ключ = id), история правок -
блоб-массив на заметку. Логика в [`lib/store.mjs`](lib/store.mjs), вся серверная часть -
одна функция [`netlify/functions/api.mjs`](netlify/functions/api.mjs). Отдельную БД поднимать
и оплачивать не нужно.
